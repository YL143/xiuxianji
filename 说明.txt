修仙纪 · 本地单机修真（基础框架）
====================================

【怎么启动】
  双击本目录下的「修仙纪」（快捷方式），或「启动游戏.bat」。
  窗口打开即可游玩，不需要联网，不需要安装任何东西。
  首次启动约 1~2 秒（要先把源码编译进内存）。

【安装到别的位置】
  双击「安装到其他位置.bat」，选一个文件夹，会在其中创建「修仙纪」子目录，
  自动生成桌面与开始菜单快捷方式、卸载入口（设置 → 应用 里可见「修仙纪」）。
  安装后原目录可以删掉；存档会一并搬过去。
  卸载：开始菜单里的「修仙纪 卸载」，或设置 → 应用 → 修仙纪 → 卸载。

【存档在哪】
  默认保存在程序目录的  save\xiuxian.sav
  纯文本，可直接备份或拷走；每 20 秒自动保存，关窗时也会保存。
  如果程序装在 Program Files 这类没有写入权限的位置，
  存档会自动改存到  %LOCALAPPDATA%\修仙纪\save\xiuxian.sav
  删掉存档文件就回到初始状态，游戏内也可以「重开一世」。

【为什么不是普通 exe】
  这台电脑开启了 Windows「智能应用控制」（Smart App Control），
  未签名的 .exe 会被系统直接拦截（提示“应用程序控制策略已阻止此文件”）。
  所以这里用 Windows 自带的 PowerShell 承载同一个原生窗口程序：
  界面、操作、存档和普通桌面程序完全一样，只是启动方式不同。
  目录里的「备用exe\修仙纪.exe」供关闭了智能应用控制的电脑直接双击运行。

【安装包】
  上一级的「修仙纪安装程序.exe」是标准 Windows 安装程序（选择路径、
  桌面/开始菜单快捷方式、卸载项），但它是未签名程序，同样会被本机的
  智能应用控制拦截；换一台没开这项策略的电脑就能直接双击安装。

【当前已实现（框架）】
  · 打坐吐纳自动积累修为；九层为一境，共九大境界（炼气→渡劫）
  · 九层圆满后可「冲击瓶颈」，成功率受悟性与破境丹影响，失败折损半数修为
  · 采药得灵石、历练搏机缘（灵石 / 修为 / 悟性 / 受伤 / 丹药）
  · 商铺：聚气丹（12 分 ×1.5）、破境丹（突破 +20%）、悟道茶（永久悟性 +1）
  · 寿元随修行流逝，寿尽坐化 → 转世重修，累积「道韵」永久加速
  · 离线结算：关窗后仍在修行，单次最多结算 8 小时（效率 0.8）
  · 渡劫九层圆满可飞升，进入下一轮轮回
  · 全部数值即时结算、本地存档，无任何网络请求

【快捷键】
  空格 = 打坐凝气      B = 冲击瓶颈      回车 = 确认弹窗
