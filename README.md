## 这是什么

《修仙纪》是用 **C# + .NET Framework WinForms** 写的桌面小游戏，整个项目只有 6 个 `.cs` 文件、约 2400 行代码，不引用任何第三方库，不发一个网络请求。

程序不是传统意义上的"编译产物 + 双击运行"，而是启动时把 `src/*.cs` 读进内存、由 PowerShell 调 `Add-Type` 现场编译成一个窗口程序。改完源码重开游戏即生效，不需要重新打包。

## 玩法

围绕"时间流逝"做的修真循环：

- **打坐吐纳** —— 修为自动累积，九层为一境，共九大境界（炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫）
- **冲击瓶颈** —— 九层圆满后可冲关，成功率受悟性、破境丹影响；失败折损半数修为并受创静养
- **采药 / 历练** —— 采药稳得灵石，历练搏机缘（灵石、修为、悟性、受伤、丹药）
- **商铺** —— 聚气丹（12 分钟 ×1.5 吐纳）、破境丹（突破 +20%）、悟道茶（永久悟性 +1）
- **寿元与轮回** —— 年岁随修行增长，寿尽坐化后转世重修，累积「道韵」永久加速下一世
- **离线结算** —— 关窗后仍在修行，单次最多结算 8 小时（效率 0.8）
- **飞升** —— 渡劫九层圆满可飞升，进入下一轮轮回

数值全部即时结算并存于本地，每 20 秒自动保存，关窗时再存一次。

**快捷键**：`空格` 打坐凝气 · `B` 冲击瓶颈 · `回车` 确认弹窗

## 快速开始

### 方式一：绿色运行（推荐，不涉及 exe）

下载仓库后双击 `启动游戏.bat` 即可。窗口打开就能玩，不需要联网，不需要安装任何东西（首次启动约 1~2 秒，用于把源码编译进内存）。这条路径完全不碰 exe，所以不受签名策略影响。

### 方式二：安装到本机（安装包未签名）

`dist/修仙纪安装程序.exe` 是标准 Windows 安装包：可选安装路径，自动创建桌面与开始菜单快捷方式、卸载入口（在「设置 → 应用」里可见）。

> [!NOTE]
> 该安装包**未签名**，见上方警告。下载后如被拦截，右键 → 属性 → 勾选「解除锁定」，或在「Windows 安全中心」里选择仍要运行。

## 目录结构

```
.
├── src/                  # 全部游戏源码
│   ├── Program.cs        # 入口
│   ├── MainForm.cs       # 窗口与生命周期
│   ├── GameCanvas.cs     # 界面布局与全部绘制（约 1400 行）

│   ├── GameData.cs       # 境界、寿元、修为曲线等数值表

│   └── app.manifest      # DPI 感知与权限声明
├── assets/app.ico        # 图标
├── app.ps1               # 启动脚本：编译 src 并承载窗口
├── lib.ps1               # 构建函数 Build-GameTypes
├── 启动游戏.bat          # 隐藏控制台启动 app.ps1
├── 说明.txt              # 面向玩家的使用说明
├── 预览.png              # 游戏截图
└── dist/                 # 打包好的 Windows 安装程序（未签名）
```

## 开发

想改数值就动 `src/GameData.cs`：境界名、寿元加成、修为需求曲线（`NeedBase` / `NeedGrowth`）、产出速率、物价与各类概率都集中在这里。

想加玩法就动 `src/Engine.cs`（结算逻辑）和 `src/GameCanvas.cs`（界面）。`Engine` 只负责状态推进，UI 每帧读取状态绘制，两者之间没有事件耦合。

改完直接重开游戏即可看到效果 —— 源码在启动时编译，没有构建缓存。

**技术栈**：C# 5 · .NET Framework 4.x · System.Windows.Forms · System.Drawing（GDI+ 直绘，无 UI 框架）
